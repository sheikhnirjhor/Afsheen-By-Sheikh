# 10 - User Stories

## 1. Guest Stories

| ID | Story | Priority |
|----|-------|----------|
| US-01 | As a visitor, I want to browse products by category so I can find items I'm interested in | P0 |
| US-02 | As a visitor, I want to view product details (image, description, price, sizes, reviews) so I can make informed decisions | P0 |
| US-03 | As a visitor, I want to search for products by name so I can find specific items | P0 |
| US-04 | As a visitor, I want to add products to my cart so I can purchase them later | P0 |
| US-05 | As a visitor, I want to view the hero banner carousel to discover featured products | P1 |
| US-06 | As a visitor, I want to browse flash sale products with countdown timers to find deals | P1 |
| US-07 | As a visitor, I want to navigate categories via circular icons | P1 |
| US-08 | As a visitor, I want to use the mega menu to quickly find product categories | P1 |
| US-09 | As a visitor, I want to read customer testimonials so I can trust the brand | P2 |
| US-10 | As a visitor, I want to view the About page to learn about the brand's heritage | P2 |
| US-11 | As a visitor, I want to find store locations and contact information on the Contact page | P2 |
