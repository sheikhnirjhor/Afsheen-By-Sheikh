# 02 - Problem Statement

## 1. Background

Afsheen by Sheikh is a Bangladeshi luxury brand specializing in heritage Bengali couture (Dhakai Jamdani, Banarasi Katan, Rajshahi Silk), fine filigree jewelry, and botanical skincare products. The brand operates physical stores in Gulshan, Dhanmondi, and Tatibazar, Dhaka, but lacks a digital storefront.

## 2. Problem

The brand faces the following challenges:

1. **Limited Reach** — Physical store locations restrict customer access to Dhaka residents only
2. **No Online Presence** — Customers in other districts (Chittagong, Sylhet, Rajshahi) cannot browse or purchase products
3. **Manual Order Management** — Orders are tracked manually, leading to inefficiencies
4. **Brand Discovery** — New customers are unaware of the brand's heritage collections and imported skincare lines
5. **Customer Support Gap** — No real-time channel for customer inquiries and support

## 3. Proposed Solution

Build a full-stack e-commerce web application that:

- Showcases the complete product catalog (24 products across 10 categories) with rich descriptions and images
- Enables online browsing, cart management, and checkout (Cash on Delivery / bKash / Nagad / Card)
- Provides admin tools for product and order management
- Offers a moderator dashboard for live customer chat support
- Presents the brand story through an About page and customer testimonials
- Supports responsive design for mobile-first browsing (common in Bangladesh)
- Includes flash sale promotions with countdown timers
- Supports wishlist functionality and multiple coupon codes

## 4. Target Impact

| Metric | Current | Target |
|--------|---------|--------|
| Geographic reach | Dhaka only | All districts in Bangladesh |
| Order tracking | Manual | Digital dashboard with progress tracking |
| Product discovery | Word of mouth | Online storefront with search/filter/sort |
| Customer engagement | In-store only | Reviews, testimonials, FAQ, live chat |
| Customer support | Phone only | Live chat widget with moderator interface |
